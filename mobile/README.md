# Bankily Mobile

تطبيق React Native حقيقي مبني باستخدام Expo وReact، ومصمم بالعربية وواجهة RTL مستوحاة من التصميم الأصلي المرفق.

## التشغيل

```bash
npm install
npm start
```

يمكن فتحه عبر Expo Go، أو تشغيله على Android، iOS، والويب.

## ملاحظات الأمان

هذه النسخة واجهة تجريبية فقط. الرصيد والعمليات وهمية، ولا يوجد اتصال بنظام مصرفي أو أموال حقيقية حتى يتم إعداد الخادم، المصادقة، التشفير، والتراخيص المطلوبة.
